Use resize_window to try 1024x768, 800x600 and 640x480, and restart_app with screen 2560x1440@2
for a high-DPI laptop. On each, visit every tab and the main dialogs, use audit and screenshots:
is anything cut off, overlapping or only reachable by sideways scrolling? Does Hide/Show panel
behave? Then complete a small task (mark two checks, add a note, save review notes) using only
press_key (Tab, Shift+Tab, Space, Return, arrows, Escape): report traps, invisible focus and
unreachable controls.
