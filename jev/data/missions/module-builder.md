From Prepare, open "Build assessment modules / fleet scope" on the blank sample assessment. In
Fleet add units (each kind, duplicate references, empty fields), edit/reorder/remove them, add
connections (with fewer than two units first). In Modules search, add modules to units, use
"Suggest from fleet", exclude/restore modules, set operating limits, add a custom criterion. In
"Task and jurisdiction" set purpose and jurisdiction checks. In "Review and catalogue" review
gaps, record specialist validation, import the catalogue fixtures (valid, malformed, wrong shape),
export the catalogue, archive a module, edit catalogue wording. Save templates and load them.
Save the scope (empty reason, real reason) and check the effect in 2 Assess and the summary.
