You are opening DT for the first time. Create a vault in the sandbox (for example
vaults/first-vault) and get to the main window. Before succeeding, try the ways a new user can
go wrong: no folder, a folder that is not empty (vaults/ already contains things once you create
one), a passphrase that is too short, exactly 11 and 12 characters, spaces only, forgetting the
"create" tick, opening a non-vault folder, the wrong passphrase on an existing vault, Cancel.
Use "Choose folder" once to see the folder chooser. Once in, look around the header: Help guide
(F1) and every help topic against what the screens actually say, appearance toggle, Hide/Show
panel. Finish by locking and unlocking (including a wrong passphrase at unlock).
