Create a new assessment and fill in Prepare completely as a trainer would. Check the automatic
capital letter on name fields when you leave them (and that IDs are not changed), the licence
class dropdown and typing your own value, truck and trailer make/model dropdowns and the note for
unlisted vehicles, the jurisdiction list, the four preparation checkboxes, Insert parameter
(empty name, duplicate name, odd characters), Save preparation, Save driver/vehicle to directory
(with and without an assessor name) and then "New from directory". Switch records and come back:
is everything still there? Try the registration check buttons (recording one manually, invalid
plates).
